One line of office humour. This program writes a single original joke — 131 characters, one line, no trailing newline — to `/output/entry.txt`: a plea to stop hitting reply-all that is itself answered by a reply-all avalanche, all forty-seven colleagues agreeing at the same time, in the same thread.

## Run it

```sh
node main.ts
```
